What to do next
01 Extract the downloaded env.zip and place the .env file inside into your project folder — the same folder as package.json. Replace any existing .env file.
02 Double-click start.bat to launch the app. Use start-quick.bat if you don't have a permanent domain set up.
03 Open http://localhost:3000 in your browser. Go to Settings to set up your donation rules and timer duration.
04 Add http://localhost:3000/overlay as a Browser Source in OBS. Customize the look in the Overlay Settings tab.
